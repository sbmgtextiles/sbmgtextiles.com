SBMG PRODUCT GALLERY EDITION

- Catalogue section removed.
- Product cards open detailed popups.
- Each product supports 2 or 3 photos.
- Main image can be zoomed and dragged.

HOW TO ADD A PRODUCT
1. Upload 2-3 photos into images/products.
2. Open https://sbmgtextiles.com/admin.html
3. Click + Add Product.
4. Enter details and photo paths, for example:
   images/products/style-front.jpg
   images/products/style-side.jpg
   images/products/style-back.jpg
5. Download products.js.
6. Replace data/products.js in GitHub.
7. Commit and wait 1-5 minutes.

Recommended image size: 1200 x 1500 px, JPG or WebP, under 1 MB each.
