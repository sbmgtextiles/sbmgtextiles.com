Simple update process

  1. Upload your PDF or image into the correct GitHub folder.
  2. Open admin.html, enter the file path and other details.
  3. Click the green download button.
  4. Upload the downloaded JavaScript file into the data folder and replace the old one.
  5. Wait 1–5 minutes and refresh your website.
