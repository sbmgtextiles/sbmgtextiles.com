Catalogue Manager

Add, edit or remove PDF catalogues. Then download the updated catalogues.js and upload that one file to GitHub.

Important: This page works without a server. Changes remain in this browser until you export the file. It does not directly update GitHub.

Your catalogues

Use the exact PDF filename you will upload into the catalogues folder.

After downloading, replace the old catalogues.js in GitHub.

Simple upload steps

  1. Prepare your catalogue as a PDF, for example summer-2027.pdf.
  2. Open this manager and click + Add Catalogue.
  3. Enter catalogues/summer-2027.pdf in PDF path.
  4. Click Download Updated catalogues.js.
  5. In GitHub, upload the PDF inside the catalogues folder.
  6. Replace the main catalogues.js file with the downloaded one.
  7. Wait 1–5 minutes and refresh the website.

Cover image (optional)

Upload a cover image inside images/catalogues, then enter a path such as images/catalogues/summer-2027.jpg. Leave it blank to use the premium automatic cover.
